# MaNikki4 运行与基准适配环境规范

为了确保视觉特征比对、模板匹配置信度与 OCR 识别率达到最稳定的工业级水准，本项目所有视觉资产与流水线节点均在标准基准环境下开发调校。

---

## 1. 模拟器运行基准

| 配置项 | 基准要求 | 说明与避坑细节 |
| :--- | :--- | :--- |
| **模拟器型号** | **MuMu 模拟器 12** | 强烈推荐使用 MuMu 12（基于 Android 12 核心）。Go Agent 内置了对 MuMu 12 默认注册表、安装路径及 `MuMuManager.exe` 进程的自适应探测。 |
| **ADB 调试开关** | **必须开启** | 在 MuMu 模拟器「设置中心」➔「开发者选项 / 其他设置」中，勾选开启 **「本地 ADB 调试」**。Agent 依靠 ADB 端口向模拟器发送控制信令。 |
| **屏幕方向** | **竖屏 (Portrait)** | 《闪耀暖暖》为标准竖屏手游，模拟器不可强制横屏或自由旋转。 |
| **基准分辨率** | **`720 × 1280`** (9:16) | 开发基准分辨率。MaaFramework 具备等比自适应缩放（`display_short_side: 720`），可适配更高分辨率的等比竖屏（如 `1080 × 1920`），但建议直接设为 `720 × 1280` 获得最轻量流畅的渲染。 |
| **屏幕 DPI** | **默认推荐** (如 320 DPI) | DPI 保持模拟器默认即可，不会影响相对像素几何坐标推算。 |

## 2. 游戏内 UI 主题铁律：必须为 “暖调回忆”

### 为什么强制要求 “暖调回忆” 主题？
《闪耀暖暖》游戏允许玩家更换主界面大厅的主题皮肤（如活动专属主题、冷色系主题等）。但在自动化感知层面上，换肤主题会引入以下不可控干扰：

1. **返回按键视觉指纹漂移**：
   * 左上角返回按键（`闪暖-返回箭头.png`）是全流程退出的核心锚点。
   * 在“暖调回忆”主题下，箭头为标准的暖白色带微光辉，底盘半透明度适中。
   * 在部分暗黑或梦幻冷色主题下，该箭头边缘会融入冷色渐变，或底盘透明度骤升，导致 Template Matching 的置信度（Score）跌破判定阈值（Threshold 0.7）。
2. **大厅入口色调与发光粒子**：
   * “暖调回忆”主题底色温和，文字与背景反差鲜明，PP-OCR 对底部“设计中心”、“开始”等入口文字的召回率接近 100%。
   * 部分动态主题附带强烈的全屏流星、雨雪等动态粒子特效，会直接污染 OCR 识别矩形，引起误触发或超时重试。
3. **资产采集基准**：
   * 项目所有模板图采样、ROI 截取均在“暖调回忆”环境下完成。因此使用者必须将主界面设为该默认经典主题。

## 3. 游戏内制衣引导槽位基准

为避免用户在桌面辅助软件内反复选择章节与材料关卡，本项目直接复用游戏内 **【设计中心】➔【制衣引导】** 的槽位机制：

```
+-------------------------------------------------------------+
|                     【制衣引导】目标配置                     |
+------------------------------+------------------------------+
|     【第 1 套】(左侧卡槽)    |     【第 2 套】(右侧卡槽)    |
|                              |                              |
|   推荐：时空回廊困难目标套装 |   推荐：普通主线 / 工坊目标套|
|     (如微光、闻人典等)       |       (如章节必做套)         |
|                              |                              |
|   对应任务：👗 时空回廊制衣   |   对应任务：🧵 主线制衣      |
+------------------------------+------------------------------+
```

* **安全原则**：任一套装材料刷满后，游戏会弹窗显示“材料已收集完毕”，脚本通过 OCR 识别到该标志后自动判定任务完成并优雅返回，绝不空转浪费体力。
